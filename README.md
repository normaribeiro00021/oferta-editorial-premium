# Oferta Editorial Premium

Vamos criar uma página de vendas para um infoproduto seguindo a matéria prima da oferta em anexo.

REGRA FIXA: Essa página de vendas deve ser feita 100% para mobile-first e super otimizada para rapidez no connect rate.
IMPORTANTE: A página será no idioma PORTUGUÊS-BR buscando proximidade com a linguagem utilizada pela população local do país.

Use todas as diretrizes, paleta de cores (Azul Profundo #192D48, Verde Petróleo #168B8C, Coral #E5796C, Branco #FFFFFF), tipografia (Manrope e Inter), estilo visual editorial psicológico premium, headline, subheadline, mecanismo central, seções de casos, quebra de objeções, módulos, bônus, garantia, depoimentos, FAQs e precificação detalhadas no arquivo da oferta para estruturar a página de vendas completa.
